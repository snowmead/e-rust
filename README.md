# e-rust

A Rust coding skill covering language features, standard-library APIs, and code conventions.

## Install

With [Bun](https://bun.sh) installed, run this from your project directory:

```sh
bunx skills add snowmead/e-rust --skill rust
```

Follow the prompts to choose your coding agent. Add `--global` to install the
skill for use across projects. See the [skills CLI documentation](https://github.com/vercel-labs/skills#installation-scope) for installation options.
